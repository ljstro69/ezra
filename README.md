## Upload to GitHub
1. Download and unzip this archive on your computer.
2. Open the `ljstro69/ezra` repository in GitHub and choose **Add file → Upload files**.
3. Drag the extracted **app** and **public** folders plus `package.json` and `README.md` into the upload area. Do not upload the ZIP itself.
4. Commit the changes to `main`. Vercel should redeploy automatically.
5. After deployment, refresh the live site and check **The Ezra Promise** and **Contact Us** pages. Send a test inquiry if desired.

Do not delete the existing repository before uploading.
